## Profile

I'm a **generalist developer** with an interest in building practical software and understanding how systems behave internally.

My work spans **web development**, **backend APIs**, **native Android/C++ development**, **AI-assisted engineering workflows**, and **reverse engineering research**. I use reverse engineering as a learning and research discipline, especially for understanding runtime behavior, binary structure, native libraries, and application architecture in authorized contexts.
